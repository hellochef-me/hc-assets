# Approved screen implementation

Use the three approved scan, update and existing-serial boards as the visual brief. Preserve Hello Assets branding. This is an intentional continuation of the user's cream/coral direction.

Palette: warm canvas #FBF4EB, white #FFFFFF, charcoal #292524, coral #D53D26 (darkened where required for readable white text), teal #17634F and amber #925000. Keep the existing sans-serif stack, with 28–34px screen titles, 18–22px card headings, 16px form controls and quieter 13px helper text. Icons remain Lucide.

Left-aligned, mobile-first screens place the actual device image above identity and ownership. Use one primary action per step and outlined secondary actions. Match prompts take over the scan screen so users cannot accidentally continue registering. The edit screen retains identity and offers a separate review of changed values before saving. Reassignment remains independent and preserves its movement event.

Desktop uses a focused central workflow and a two-column detail layout; mobile uses full-width cards, a large photo, and bottom actions. Do not insert stock device photos into real records. Empty photos use the category icon in an intentional portrait placeholder. Avoid oversized empty cards, repeated explanatory text and unnecessary uppercase labels.

Keep exact-match blocking, explicit near-match review, old-link aliases, temporary label photos, confirmed writes, idempotency and version checks. Visual polish must not replace these safeguards. Check keyboard focus, cancellation, interrupted saves, thumbnail replacement and duplicate scans with fictional fixtures before release.
